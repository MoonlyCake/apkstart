# ApkStart：运行时、应用会话与 IPC 边界

基线：`349acdc83483da739cb3293fefdc0cff220ab456`。方案原先基于 v0.6.2；本文记录对当前代码实际采用的改动，不将方案里的故障归因、体积或性能估算当作实测。

## 生产路径

- **运行时**：`src/application/runtime-lifecycle.js` 串行处理受管安卓实例的启动、停止、重启和维护。相邻启动请求可以复用同一次结果；其间如果有停止、换屏或维护请求，就不能合并。换屏在单次队列任务内完成关机、写面板配置、开机；未确认关机不写配置。排队任务失败不会堵住后续命令。网络修复只重连或冷启动，不再隐式清空数据。自动关机只接受有效的活动探测，排队后再次确认没有打开新会话。已使用的安卓数据继续绑定原系统镜像；下载了新镜像或遇到 ABI 错误都不是清空旧数据的许可。VM 层不再持有前台应用清单。
- **应用会话**：`src/application/app-sessions.js` 管理应用窗口令牌、前台、停放与应用级后台任务。旧窗口的关闭回调只处理自己的令牌。启动在等待开机、接窗或重新找包时失去会话，不再向安卓提交新的启动请求；一次运行时切换也会作废旧的 ADB 租约。物理面板已切换而应用恢复失败时，分别报告这两个结果。
- **Electron IPC**：`src/ipc/dispatch.js` 是唯一注册点；业务处理按领域拆为 12 个模块，启动画面另有薄适配器。旧 preload 的 122 个 invoke 通道仍在，也恢复了应用列表的变更通知。各通道保留所需的输入判断、返回值和确认框；不新建一套全局 API，也不维护旧分发器副本。
- **Windows 窗口代理**：只有 TCP 握手成功才算启动完成；握手超时或拒绝可重试，旧进程或连接的迟到事件不干扰新一轮。没有重写 PowerShell/C# 代理。
- **AEHD 提权**：两条入口共用同一验证流程，仅从 Google 官方 HTTPS 下载固定版本，按[官方 SDK 索引](https://dl.google.com/android/repository/addon2-3.xml)核对大小和 SHA-1。旧压缩包重新核对，每次从验证过的字节解包，不提升旧的已解压文件。该检查不是代码签名，也不宣称消除 UAC 等待期间的同用户进程篡改风险。不把这项改动误称为所有下载均已校验。

## 不照搬的建议

- **2 GB 默认数据分区**：当前 Quick Boot 的 QCOW2 差量盘无法依靠现有路径无损自动扩容；配置容量也不能直接推算实际磁盘占用。没有减小默认分区。
- **双 AVD 换向**：只共用只读镜像不能共用应用、账号与快照；两台预热还有额外内存与 I/O。没有开启双实例，也不承诺换向快了多少。
- **用 `adb track-app` 代替进程就绪**：不把调试观察器当作所有 APK 的存活依据。继续使用现有的进程观测与不确定结果区分。
- **按行数判定完成、保留整套旧 IPC、一次拆完原生宿主**：不用这些作为验收。主进程的窗口装配、发布更新等还留在主入口；后续根据回归价值拆分。

## 可重复验证

`npm test`（或 `npm run test:rewrite`）运行真实 JavaScript 业务入口搭配合成 ADB、窗口代理、进程与文件夹具，覆盖重复启动、失败后继续、换屏队列、旧关窗不作用于新窗口、IPC 通道契约、提权前验包和失败清理。合成轨迹与记录格式在 `test/harness/`。工作流脚本：`.codex/workflows/apkstart-architecture.workflow.mjs`。

离线回放不等于真实轨迹；尚未验证 Windows 多 DPI/嵌入窗口、真实安卓冷启动或换屏、麦克风与耳机、AEHD 安装、启动时延或 FPS。
